good to know

  • PhysBones and VRM spring bones move differently, so values are mapped approximately. Tune them with the Stiffness, Drag and Gravity sliders.
  • Angle limits, immobile, stretch and grab have no VRM 1.0 equivalent and are skipped.
  • Happy, angry, sad, relaxed and surprised are not created, since VRChat has no standard for them. Add them in UniVRM afterwards.
  • VRCFury and Modular Avatar need no extra step: the converter builds a copy the way an upload does, then converts that copy.
  • Your avatar is never changed. The converter works on a copy and deletes it after export.

install

  1. add the listing

    Click add to VCC, or paste the URL in the Creator Companion under Settings › Packages › Add Repository.

    {{ listingInfo.Url }}

  2. add the package

    Open your avatar project (Unity 2022.3.22f1) in VCC and add {{ name | html.escape }}.

  3. let it fetch UniVRM

    Unity asks to add UniVRM. Click Add. It matches any UniVRM the project already has and comes from OpenUPM, so you don't need git.

  4. convert

    Open Tools › VRChat to VRM 1.0, drop in your avatar, fill in name, authors and license, then click Export VRM 1.0.
